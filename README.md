# Science Hub

Локальная AI-среда для инженерных и исследовательских проектов. Python-сервер, веб-интерфейс на русском, SQLite и файлы на вашем компьютере. Модели подключаются через API; провайдер и модели меняются в настройках без изменения кода.

## Быстрый запуск

Нужен Python 3.11+. В готовом архиве интерфейс уже собран — Node.js для запуска не нужен.

Установка из GitHub требует также Git, Node.js 22+ и npm:

```sh
git clone https://github.com/art9762/Science-Hub.git
cd Science-Hub
python3 setup.py
.venv/bin/python run.py
```

На Windows вместо `python3` используйте `python`; после установки запустите `start.bat`.

Для распакованного архива:

```sh
python3 setup.py
.venv/bin/python run.py
```

На macOS можно открыть **Start Science Hub.command**. На Windows — **start.bat** либо `.venv\Scripts\python run.py`. Приложение открывает браузер по адресу `http://127.0.0.1:8765`. Сервер слушает только локальный интерфейс.

При установке из исходников для первой сборки интерфейса нужен Node.js 22+ и npm. Если установлен `uv`, установщик использует версии из `uv.lock`; иначе устанавливает зависимости в `.venv` через pip. Интернет нужен для первоначальной установки зависимостей.

## Первый проект

1. Создайте проект и опишите задачу.
2. Откройте **Настройки**. Укажите Base URL и API-ключ, загрузите каталог моделей и выберите модель оркестратора. Для CheapVibeCode Base URL: `https://ru.cheapvibecode.ru/v1`.
3. Загрузите источники в **Базу знаний**. Найдите нужный фрагмент, откройте документ и выделите текст для аннотации.
4. В **Офисе агентов** настройте роли, инструкции, модели и инструменты. В новом проекте уже есть восемь специалистов.
5. На рабочем столе создайте чат и задайте вопрос или запустите командную задачу. Документы можно выделить для внимания, специалистов — выбрать для команды. Ход работы, сообщения, ошибки и результат сохраняются в беседе.
6. Редактируйте созданные материалы в **Документах**, связывайте объекты в **Графе и решениях**, раскладывайте заметки на **Доске проекта**.

## Возможности

- Отдельные проекты с изолированными файлами, документами, агентами и историей.
- Несколько постоянных чатов внутри проекта: отдельная переписка и общие материалы, доска и результаты команды.
- Импорт PDF, DOCX, TXT, Markdown, HTML и распространённых растровых изображений. HTML преобразуется в текст; загруженные скрипты не исполняются.
- Извлечение текста по страницам PDF, локальное OCR изображений и сканированных PDF, поиск по тексту, описаниям, метаданным и аннотациям.
- Просмотр оригинала и извлечённого текста, постоянные цветные выделения и заметки с привязкой к странице и тексту. Страницы PDF отрисовывает локальный Python-сервер, поэтому просмотр не зависит от PDF-плагина браузера.
- Отдельное мультимодальное описание изображения через выбранную vision-модель; оно также участвует в поиске.
- Восемь начальных ролей: инженер, аналитик, исследователь, критик, фактчекер, технолог, сметчик и пессимист. Создание и редактирование своих агентов.
- Оркестратор с выбором инструментов и специалистов самой моделью: чтение базы знаний, исследования, безопасные арифметические расчёты, делегирование, документы, решения и утверждения с источниками.
- Тёмная и светлая темы, большой чат, статусы специалистов сверху и раскрываемый ход работы снизу.
- База знаний в виде сетки файлов с вложенными папками и переносом перетаскиванием или через меню.
- Асинхронные задачи, журнал событий, остановка и сохранение промежуточного результата. Работа продолжается после закрытия вкладки, пока запущен Python-сервер.
- Поиск через подключаемые адаптеры DuckDuckGo, arXiv и GitHub; чтение текста найденных публичных HTML/PDF-источников.
- Веб-источники сохраняются в базе знаний: результаты AI-поиска автоматически, результаты ручного поиска — кнопкой. Полный прочитанный текст заменяет поисковый фрагмент в том же источнике.
- Импорт YouTube по ссылке: название, автор и субтитры с временными метками, доступные для поиска и чтения командой. Анализ использует субтитры; кадры и звук ролика не обрабатываются.
- Общие инструменты чтения материалов проекта и работы с доской у оркестратора и специалистов.
- Рабочие документы с экспортом в Markdown, TXT, DOCX и PDF.
- Граф связей, дерево решений с альтернативами, утверждения с источниками и оценкой уверенности, свободная доска с сохранением координат.
- Несколько OpenAI-совместимых шлюзов и динамический каталог моделей; для других протоколов предусмотрен реестр Python-адаптеров.

## Данные и API

`data/science-hub.sqlite3` содержит проекты и историю; `data/files/` — оригиналы документов. `data/settings.private.json` хранит настройки провайдеров. Секреты можно также задать в `.env` по примеру `.env.example`. Ключи не возвращаются браузеру и исключены из Git и архива для передачи.

Хранение локальное, но при обращении к AI выбранный контекст проекта передаётся настроенному API-провайдеру. Анализ изображения передаёт изображение. Интернет-поиск передаёт текст поискового запроса соответствующему источнику. Без API-ключа доступны документы, поиск по локальной базе, аннотации, доска и редактирование материалов; AI-функции требуют подключения к провайдеру.

Для резервной копии остановите сервер и скопируйте каталог `data/` и `.env`. В резервной копии могут быть секреты. Для передачи приложения другому человеку используйте `artifacts/ScienceHub.zip`, который не содержит ваших данных и ключа.

## OCR и шрифты

Для OCR нужен локально установленный Tesseract. На macOS:

```sh
brew install tesseract tesseract-lang
```

На Debian/Ubuntu: `sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng fonts-dejavu-core`. На Windows установите Tesseract и добавьте его каталог в `PATH`. Приложение автоматически использует доступные русский и английский языки. Если OCR отсутствует, интерфейс показывает это; оригинал остаётся доступен.

Сканированные PDF обрабатываются с ограничением числа OCR-страниц за импорт; неполная обработка обозначается предупреждением. Для PDF-экспорта кириллицы используется установленный Unicode-шрифт (Arial, DejaVu Sans или Liberation Sans). Это текстовый экспорт, без точного воспроизведения исходной вёрстки.

## Границы первой версии

- Это однопользовательское локальное приложение. Здесь нет серверных учётных записей, совместного редактирования и доступа из локальной сети.
- Поиск локальный текстовый, без векторной базы и семантических embeddings. Для очень больших библиотек потребуется отдельный индекс и постраничная выдача.
- Цветные аннотации привязаны к извлечённому тексту; они не записываются в оригинальный PDF. Страницы DOCX зависят от редактора, поэтому DOCX показан как единый текст.
- Уверенность модели и сигналы противоречий — проверяемые гипотезы с источниками, а не статистически откалиброванные вероятности. Они не гарантируют правильность инженерного решения. Проверка ограничена прочитанными источниками и бюджетом задачи.
- Автономность ограничена временем: по умолчанию 10 минут исследования и ещё 60 секунд на завершение и сохранение. После этого запросы и агенты останавливаются принудительно. Лимита числа шагов нет; лимит токенов задаётся на один ответ модели. При перезапуске сервера незавершённые задачи отмечаются прерванными; автоматического повторного списания за возобновление нет.
- Поддержка инструментов и изображений зависит от выбранной модели и шлюза. Ошибки провайдера видны в журнале. Публичные поисковые источники могут ограничивать запросы. Чтение веб-источников ограничено 16 000 символами/первыми пятью страницами PDF; страницы, требующие JavaScript или авторизации, могут не читаться.
- Для YouTube нужны публичный ролик и доступные субтитры. При блокировке запросов, отсутствии субтитров или закрытом видео импорт сообщит об ограничении; расшифровку можно загрузить текстовым файлом.
- Внешние ссылки сохраняются как источники; приложение не исполняет найденный код и не предоставляет агентам доступ к терминалу или произвольным локальным файлам.

## Разработка

```sh
uv sync --frozen
cd frontend
npm ci
npm run dev
```

В другом терминале из корня проекта:

```sh
uv run python run.py --no-browser --reload
```

Vite работает на порту 5173 и проксирует `/api` на 8765. Для обычного запуска:

```sh
cd frontend
npm run build
cd ..
uv run python run.py
```

Проверки и сборка архива:

```sh
uv run pytest -q
uv run ruff check backend tests run.py setup.py scripts
python3 scripts/package_release.py
```

Интерактивная документация API: `http://127.0.0.1:8765/docs`. Контракт модулей — [API_CONTRACT.md](API_CONTRACT.md), исходное ТЗ — [docs/IDEA.md](docs/IDEA.md).

## Структура

```text
backend/
  app.py          HTTP, локальная граница доступа, веб-интерфейс
  storage.py      SQLite и изоляция проектов
  documents.py    извлечение текста, OCR, экспорт
  core.py         документы, агенты, доска и CRUD
  providers.py    настройки, секреты, адаптеры моделей
  research.py     интернет-источники и расчёты
  ai.py           оркестратор, задачи и инструменты
frontend/src/     React-интерфейс
tests/            проверки API, хранения и оркестрации
data/             локальные пользовательские данные (не в Git)
```
