# Архитектура и расширение

Science Hub — однопользовательское приложение: FastAPI обслуживает REST API и собранный React-интерфейс; SQLite и оригинальные файлы находятся на том же компьютере. Для моделей используется внешний API. Потоковых токенов нет: интерфейс опрашивает состояние проекта каждые 1,5 секунды.

## Модули

| Модуль | Ответственность |
| --- | --- |
| `backend/app.py` | Жизненный цикл, HTTP-ошибки, Origin/Host, статические файлы |
| `backend/storage.py` | SQLite, изоляция проектов, файлы, поиск |
| `backend/documents.py` | Извлечение текста, OCR, PDF-отрисовка, экспорт |
| `backend/core.py` | API проектов, материалов, агентов, аннотаций, решений, доски |
| `backend/providers.py` | Приватные настройки, адаптер модели, каталог моделей |
| `backend/research.py` | Поисковые адаптеры, чтение публичных источников, калькулятор |
| `backend/ai.py` | Асинхронные задачи, оркестратор, делегирование, инструменты и vision |
| `frontend/src/` | React/TypeScript: API-клиент, экраны и компоненты |

Контракты полей и маршрутов описаны в [API_CONTRACT.md](../API_CONTRACT.md). Интерактивная OpenAPI-справка доступна на запущенном сервере по `/docs`.

## Хранение и задача AI

`Store` открывает независимые SQLite-соединения и использует WAL. Все объекты принадлежат проекту; чтение и связи проверяются в его границах. Приватные настройки провайдеров хранятся отдельно от публичного состояния. Оригиналы обслуживаются по проверенному локальному пути, а файловые пути не передаются в API-ответах.

Клиент создаёт задачу POST-запросом `/api/projects/{pid}/runs`. Сервер сохраняет запрос и запускает Runner в фоне. В одном проекте выполняется одна задача. Runner формирует контекст, отправляет запрос провайдеру, проверяет и исполняет вызовы разрешённых инструментов. Делегирование запускает коллегу с его ролью/моделью в пределах общего времени задачи. Сообщения, результаты инструментов, события и документы сохраняются по ходу работы.

Модель сама выбирает последовательность действий. Ограничения задаются доступными инструментами, выбранными документами/агентами, общим временем и защитой от циклического делегирования. JSON, напечатанный в обычном ответе, не исполняется как инструмент. Отдельный таймер переводит задачу в `wrapping_up` по мягкому сроку; указание о завершении передаётся каждой активной беседе при следующем вызове модели. `asyncio.timeout_at` ограничивает общее выполнение жёстким сроком, включая провайдера, инструменты и специалистов. Сохранение документов разрешено в период завершения; новое делегирование запрещено. При жёстком сроке статус становится `timed_out`, уже записанные результаты остаются в хранилище. Лимитов количества вызовов нет.

Отмена завершает задачу; после перезапуска сервера незавершённые задачи отмечаются прерванными.

## Документы и внешние данные

Импорт проверяет количество, размер, имена и типы файлов. PDF хранит текст по страницам; сканы проходят ограниченный OCR. Для оригинального просмотра PyMuPDF создаёт PNG до 1600 px по длинной стороне. DOCX не имеет стабильной пагинации и представлен единым извлечённым текстом. Аннотации используют страницу, точные Unicode-смещения и цитату.

Инструменты чтения проверяют scope документов, маскируют ignore-фрагменты и ограничивают объём результата. Изображения передаются vision-модели как изображения. Интернет-модуль разрешает чтение найденных публичных URL, проверяет адреса/редиректы и ограничивает размер/время. Найденные документы и веб-страницы — данные, а не инструкции операционной системе.

## Расширение

OpenAI-совместимый шлюз добавляется через настройки без изменения кода. Для другого протокола реализуйте адаптер по интерфейсу `backend/providers.py` и зарегистрируйте его через `register_provider()`. Сохраняйте нормализованный формат ответов и не включайте секреты/сырые upstream-запросы в ошибки.

Новый поисковый источник добавляется в модуль `research.py` с тем же форматом результатов: заголовок, URL, фрагмент и название источника. Соблюдайте ограничения публичного чтения, проверку адресов и обработку ошибок.

Новый AI-инструмент требует схемы аргументов и обработчика в `ai.py`, проверки разрешения агента, изоляции проекта и scope. Для сохраняемых выводов используйте штатные Store/API-механизмы, чтобы интерфейс получал события и постоянные объекты. Добавляйте проверки на реальные последствия: ошибочный ID, отсутствие источника, отмена и соблюдение времени завершения.

## Проверка изменений

```sh
uv sync --frozen
uv run pytest -q
uv run ruff check backend tests run.py setup.py scripts
cd frontend
npm ci
npm run build
```

Основной набор тестов не обращается к платным моделям. OCR-тесты требуют Tesseract и могут пропускаться без него. Реальная совместимость модели проверяется отдельно с ключом: каталог моделей, tools, делегирование и vision. Результаты первой проверки и её границы см. в [VALIDATION.md](VALIDATION.md).

## Папки и оформление

`folder` — отдельный вид объекта с `parent_id`; документ ссылается на папку через `folder_id`. Отсутствие ссылки означает корень. Проверки принадлежности проекту и циклов выполняются в `Store.put` под транзакцией `BEGIN IMMEDIATE`. Удаление папки атомарно переносит непосредственные дочерние папки и документы к её родителю. Физическое расположение оригиналов при перемещении не меняется.

Цвета интерфейса используют CSS-переменные в `workspace.css`; атрибут `data-theme` задаётся до загрузки React и сохраняется в localStorage. Оригиналы изображений и PDF не перекрашиваются.
