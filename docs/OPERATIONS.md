# Установка и эксплуатация

## Требования и установка

- Python 3.11 или новее.
- Для Git-клона: Git, Node.js 22+ и npm. В подготовленном архиве `frontend/dist` уже есть, поэтому Node.js для запуска не нужен.
- Интернет для установки Python/npm-зависимостей; AI и интернет-поиск также требуют соединения.
- Дополнительно: Tesseract с языками rus/eng для OCR, Arial/DejaVu Sans/Liberation Sans для PDF с кириллицей.

macOS/Linux:

```sh
git clone https://github.com/art9762/Science-Hub.git
cd Science-Hub
python3 setup.py
.venv/bin/python run.py
```

Windows, терминал:

```bat
git clone https://github.com/art9762/Science-Hub.git
cd Science-Hub
python setup.py
start.bat
```

Можно использовать macOS-лаунчер `Start Science Hub.command`. Если macOS не позволяет запуск из скачанного архива, запустите команды в терминале. Не отключайте системную защиту. Лаунчеры повторяют установку, если отсутствует маркер её успешного завершения `.venv/.science-hub-ready`.

Установщик создаёт `.venv`, устанавливает зависимости и при необходимости собирает интерфейс. При наличии uv используется `uv sync --frozen`; без него — pip в локальном окружении. В конце создаётся `.env` из `.env.example`, если файла ещё нет. Настройте API через интерфейс или `.env`; не публикуйте этот файл.

На macOS OCR устанавливается командой `brew install tesseract tesseract-lang`. На Debian/Ubuntu: `sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng fonts-dejavu-core`. На Windows установите Tesseract и добавьте его каталог в `PATH`.

## Запуск и остановка

Обычный адрес: `http://127.0.0.1:8765`. API-справка доступна по `/docs`, состояние сервера — `/api/health`. Сервер слушает только loopback; приложение рассчитано на одного пользователя этого компьютера.

Запуск без автоматического открытия браузера:

```sh
.venv/bin/python run.py --no-browser
```

Другой порт: `run.py --port 8766`. Если экземпляр Science Hub уже работает на выбранном порту, лаунчер открывает его вместо второго сервера. Закрытие браузера не завершает сервер. Для остановки нажмите Ctrl+C в терминале, где он запущен, и дождитесь завершения процесса.

Если терминал потерян, на macOS/Linux найдите процесс через `lsof -nP -iTCP:8765 -sTCP:LISTEN`, убедитесь, что это Python именно этой копии проекта, и отправьте `kill -TERM PID`. На Windows проверьте PID через `netstat -ano` и завершите соответствующий Python-процесс через диспетчер задач. Для режима разработки отдельно остановите терминал Vite на порту 5173.

## Данные и резервные копии

По умолчанию всё хранится в каталоге проекта:

| Путь | Содержимое |
| --- | --- |
| `data/science-hub.sqlite3` | Проекты, сообщения, агенты, документы, решения и история |
| `data/files/` | Загруженные оригиналы |
| `data/settings.private.json` | Настройки и сохранённые ключи провайдеров |
| `.env` | Переменные окружения и необязательный ключ |

Чтобы сделать согласованную резервную копию, остановите сервер и скопируйте весь `data/` вместе с `.env`. Это приватная копия, содержащая ключи и материалы. Для восстановления остановите сервер, сохраните текущие данные отдельно и верните копию на прежние пути. Относительный `SCIENCE_HUB_DATA_DIR` разрешается от корня проекта.

Важные переменные:

| Переменная | Назначение |
| --- | --- |
| `SCIENCE_HUB_API_BASE_URL` | Base URL начального провайдера |
| `SCIENCE_HUB_API_KEY` | Ключ начального провайдера, если не задан в настройках |
| `SCIENCE_HUB_MODEL` | Начальная модель оркестратора |
| `SCIENCE_HUB_VISION_MODEL` | Начальная модель изображений |
| `SCIENCE_HUB_DATA_DIR` | Каталог локальных данных |
| `SCIENCE_HUB_PORT` | Порт, по умолчанию 8765 |

Сохранённые настройки могут переопределять начальные значения моделей/провайдера. После изменения `.env` перезапустите сервер. Интерфейс не возвращает ключ браузеру; Git и архив исключают локальные секреты.

## Обновление и передача

1. Остановите сервер и сделайте резервную копию.
2. Выполните `git pull --ff-only`.
3. Выполните `python3 setup.py --rebuild` (Windows: `python setup.py --rebuild`). Это обновит зависимости и соберёт интерфейс из новых исходников.
4. Запустите приложение и проверьте проект. Перед обновлением между будущими версиями прочитайте их инструкции по миграции.

Для архива, который можно передать другому человеку:

```sh
cd frontend
npm ci
npm run build
cd ..
python3 scripts/package_release.py
```

Результат — `artifacts/ScienceHub.zip`: исходники, документация и готовый интерфейс. В нём нет `.env`, `data/`, `.venv` и `node_modules`. Получателю нужен собственный API-ключ и первоначальная установка Python-зависимостей. GitHub Download ZIP содержит исходники и требует сборки интерфейса; это не тот же архив, что результат упаковщика.

## Типичные проблемы

| Симптом | Что проверить |
| --- | --- |
| Модули Python не найдены | Повторите setup.py и запускайте Python из `.venv` |
| Интерфейс не собран | Установите Node.js/npm и запустите setup.py --rebuild |
| Порт занят другой программой | Проверьте процесс или выберите другой --port |
| Каталог моделей не загружается | Base URL с `/v1`, ключ, соединение и доступ к сервису |
| Модель не вызывает инструменты/не понимает изображения | Поддержку tool calling/vision у конкретной модели и шлюза |
| OCR не работает | `tesseract --version`, `tesseract --list-langs`, PATH и языки |
| В PDF отсутствует кириллица | Установленный Unicode-шрифт из списка выше |
| Истекло время задачи | Проверьте «Ход решений» и сохранённые материалы; продолжите задачу или увеличьте время автономной работы / завершения в настройках |

Проверки проводились на macOS. Windows-лаунчер и Linux-инструкции подготовлены, но на этих ОС полный запуск не проверялся. Для разработки и расширения см. [архитектуру](ARCHITECTURE.md).
