# Покрытие исходного ТЗ

Исходный документ: `docs/IDEA.md`. Ниже указаны конкретная реализация и её границы, без обещания универсальной исследовательской автономности.

| Требование | Реализация | Границы |
| --- | --- | --- |
| Локальный Python и современный веб-интерфейс | FastAPI, React, SQLite; один локальный сервер | Один пользователь, доступ только с устройства |
| Изолированные проекты | Все объекты и файлы привязаны к project_id; межпроектные ссылки отклоняются | Нет совместного доступа |
| PDF/DOCX/TXT/Markdown/HTML/изображения | Извлечение текста, страницы PDF, MIME-проверка, локальные оригиналы | DOCX без физической пагинации; лимит 30 МБ на файл |
| Границы и количество документов | Каталог в контексте оркестратора, ID и страницы в инструментах | В контекст передаются ограниченные фрагменты; длинные страницы читаются частями |
| Выбор одного/нескольких/всех документов | Scope задачи и проверка ID на сервере | Выбор относится к базе знаний текущей задачи |
| Поиск/OCR/метаданные | Локальный поиск по извлечённому тексту, описаниям, метаданным и аннотациям | Текстовый поиск; OCR зависит от Tesseract и качества оригинала |
| Переход к фрагменту | Результат содержит страницу, цитату и точные смещения | Вкладка извлечённого текста; оригинальный PDF открывается на странице |
| Цветные аннотации | Важно, игнорировать, перепроверить, заметка; постоянные текстовые якоря | Выделения не встраиваются в исходный PDF; произвольные типы пока не настраиваются |
| Визуальное понимание изображений | Реальный image_url/base64 запрос к vision-модели; автоматический анализ при настроенной модели | Форматы и качество зависят от модели; нет притворной замены описания OCR-текстом |
| Интернет и глубокое исследование | Адаптеры DDG/arXiv/GitHub, безопасное чтение найденных HTML/PDF, источники | Ограниченное время; нет встроенного браузера для JS-сайтов и закрытых источников |
| Независимость от LLM-провайдера | Несколько OpenAI-совместимых шлюзов, конфигурация/каталог моделей, реестр адаптеров | Для другого протокола нужен Python-адаптер |
| Офис агентов | Восемь стартовых ролей, создание/изменение агентов, модели, промпты, доступные инструменты | Инструменты ограничены приложением; терминал агентам не открыт |
| Совместная работа команды | Модель выбирает делегирование, передаёт коллегам результаты и вызывает инструменты | Порядок не предписан; общее время ограничено, циклическое делегирование запрещено |
| Живое рабочее пространство | Сохранённые сообщения, журнал событий, стадии выполнения и отмена | Обновление интерфейса опросом; вывод появляется по завершении вызовов, без потокового показа токенов |
| Автономная работа | Задача продолжает выполняться без открытой вкладки | Python-сервер должен работать; после перезапуска задача не продолжает расходовать API автоматически |
| Рабочие документы | Создание/редактирование пользователем и агентами; TXT/MD/DOCX/PDF экспорт | Текстовый Markdown-редактор, базовая вёрстка экспорта |
| Память и история | История сообщений/событий, явные сохраняемые заметки памяти | Нет полной истории версий каждой правки файла |
| Граф знаний и Canvas | Интерактивный граф объектов, явные и выводимые связи, создание связей | Нет автоматического извлечения полной онтологии из всех документов |
| Дерево решений | Родительские решения, статус, аргументы, альтернативы и источники | Выбор окончательного решения остаётся за пользователем |
| Противоречия и недостаток данных | Инструменты report_conflict/request_information, ссылки на источники, инструкции оркестратора | Обнаружение зависит от модели и реально прочитанных данных, не гарантируется для всей библиотеки |
| Уровни доверия | Статус, источники, основания и явно обозначенная оценка модели/пользователя | Число confidence не является откалиброванной вероятностью; удаление источника сбрасывает подтверждение |
| Whiteboard | Перемещаемые заметки, ссылки на материалы и исследования, сохранение положения | Нет рисования от руки и совместного редактирования |

Следующие расширения естественно добавляются отдельными модулями: индекс FTS/embeddings для больших библиотек, адаптеры Tavily/Exa/Brave/MCP, версия документа, редактор пользовательских типов аннотаций, диспетчер возобновляемых задач. Они не выдаются за уже реализованные функции.
