# Проверки Science Hub

Дата: 22 октября 2026. Среда: macOS, Python 3.12, локальный браузер. Все материалы для проверок синтетические. Личные файлы и изображения не использовались.

## Реальный API

Провайдер: пользовательский OpenAI-совместимый API, Base URL `https://ru.cheapvibecode.ru/v1`. Ключ не включён в документ, исходники или архив.

- Каталог `/models`: получены 42 модели.
- `gpt-6-luna`, короткий ответ: HTTP 200, ожидаемое `SCIENCE_HUB_OK`, 43 токена суммарно.
- Командный сценарий: источник Markdown → read_document → calculate (2 × 3 = 6) → делегирование критику → его анализ недостающих данных. Шесть API-вызовов, 9 403 входных и 1 372 выходных токена. В этом сценарии лимита не хватило для сохранения отчёта; выявлен и исправлен недостаток индикации бюджета. Приложение теперь явно показывает исчерпание лимита и не исполняет JSON, который модель напечатала вместо реального вызова инструмента.
- Отдельный тест write_document: два вызова, 5 827 входных и 253 выходных токена. Рабочий документ с точным запрошенным содержимым появился в SQLite и API.
- Автоматический vision-анализ синтетической схемы: реальная передача изображения, статус `analyzed`, описание прямоугольника, стрелки, надписей и неопределённости. Это отдельный механизм от OCR.
- Реальные публичные поисковые запросы: GitHub — 6 результатов, arXiv — 6, DuckDuckGo — 8.
- Реальное чтение публичной HTML-документации Python: 16 000 символов с явным признаком обрезки. IP-pinned TLS/SNI работает; localhost, 127.0.0.1 и 169.254.169.254 отклонены.

Расход в деньгах не вычислялся: тариф шлюза не запрашивался. Нагрузка ограничена перечисленными тестами.

## Автоматические проверки

Набор проверяет изоляцию и долговечность SQLite, параллельные записи, безопасные имена/пути/HTML, откат неуспешного импорта, точность текстовых якорей и Unicode, источники/циклы решений, удаление источников, экспорты, реальные PNG/PDF OCR, границы API, приватность ключей, инструменты оркестратора, делегирование, лимиты, отмену, перезапуск, обработку ошибок, scope документов, маскирование ignore, проверку web-адресов и преобразование мультимодальных запросов.

Тесты оркестратора используют подменённый API и не расходуют ключ. OCR-тест пропускается на устройстве без Tesseract. На этой машине OCR-тест пройден.

Полный серверный набор: **36 passed**. Ruff: **all checks passed**. Предупреждения сторонних библиотек: Starlette TestClient/httpx и PyMuPDF SWIG; падений тестов нет.

## Интерфейс и сборка

Проверено в реальном локальном браузере на синтетическом проекте:

- Создание проекта и редактирование имени/инструкций агента.
- Создание рабочего документа, сохранение черновика после перехода между разделами и запись содержимого в SQLite.
- Сохранение решения с альтернативой, утверждения без выдуманного процента доверия и карточки доски; координаты карточки после перетаскивания подтверждены через API.
- Поиск фразы после Unicode-символа/эмодзи, открытие и точное выделение результата; создание аннотации «Перепроверить» выделением текста мышью и сохранение заметки.
- Просмотр извлечённого текста и оригинальной страницы PDF. Выявлена несовместимость браузерного PDF-плагина с sandbox; оригинал теперь отрисовывается локально через PyMuPDF. Номер страницы, PNG, цвета и ограничение размера дополнительно проверены автоматическим тестом.
- Настройки показывают правильный Base URL, 42 модели и сохранённое подключение, не раскрывая ключ.

TypeScript и production-сборка Vite проходят. `npm audit --omit=dev`: **0 vulnerabilities** на дату проверки. Повторный запуск `run.py` распознаёт работающий экземпляр. Лаунчеры используют маркер успешной установки и повторяют установку после незавершённого первого запуска.

Архив проверен после распаковки в новый временный каталог: импорт именно распакованного backend, health, главная страница и собранные ресурсы, создание проекта с восемью агентами и отсутствие ключа. Сканирование исходников и ZIP на совпадение с тестовым ключом: **0 совпадений**. `.env`, пользовательские данные, виртуальное окружение и `node_modules` в архив не входят. Локальные синтетические проекты после проверки удалены.
